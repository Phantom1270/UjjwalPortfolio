Student Performance

Taking a regression model from experimentation to a repeatable application.

02 Retrieval-augmented generation

Fact-Checking
Assistant

Bringing published fact-checks into the answer.

I built a knowledge base from published fact-check articles, including AltNews and BOOM Live, and implemented the retrieval pipeline from document processing to reranking.

Articles are chunked and embedded for vector retrieval. Relevant passages are reranked before being passed to an LLM, grounding the response in the retrieved source material.

My contribution
Article collection, document processing, embeddings, retrieval, reranking, and response generation.
Design decision
Retrieve published evidence before generating an answer. Coverage and source quality still limit the result.

Python · Web scraping · Embeddings · Vector retrieval · RAG

03 Geospatial data & machine learning

Landroid

A clearer picture of land health, from multiple data sources.

Built with a four-person team, Landroid combines soil, terrain, and geospatial APIs with Sentinel-2 NDVI imagery to assess land health.

I owned the scoring pipeline that brought these inputs into composite land health scores, and contributed to the data visualization and map overlays that made the results easier to interpret.

My contribution
Land health scoring pipeline, visualization, and map overlay components.
Result
2nd place at a national hackathon among 100+ teams.

Python · Sentinel-2 NDVI · GIS · REST APIs
